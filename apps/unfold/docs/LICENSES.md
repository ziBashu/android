# Third-party licenses — Unfold

Unfold itself is a ziBashu product. The following libraries ship with the app:

| Library | License | Use |
|---------|---------|-----|
| Flutter / Dart SDK | BSD 3-Clause | UI runtime |
| archive | Apache-2.0 | ZIP, EPUB, DOCX containers |
| image | MIT | PNG/JPEG/WebP decode, rotate, encode |
| markdown | BSD 3-Clause | Markdown → HTML preview/export |
| html | BSD 3-Clause | HTML parse / plain text |
| xml | MIT | DOCX and EPUB OPF/container XML |
| path | BSD 3-Clause | path joining |
| path_provider | BSD 3-Clause | recents file location |
| zibashu_ui / zibashu_core | ziBashu | branding |

No GPL or AGPL code is copied into this tree. Reference readers (Readwide, Markor, Document Viewer, Orion Viewer, KOReader) were studied only as architecture; none of their source was vendored.
