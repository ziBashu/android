# Unfold

Local-first file viewer and editor from ziBashu.

**Open. Read. Edit.**

Package: `com.zibashu.unfold`

Opens PDF, EPUB, Markdown, TXT, HTML, DOCX, DOC, images, and ZIP on the device. No account, no cloud, no network in the open path.

```
cd apps/unfold
flutter test
flutter analyze
cd ../..
.\scripts\harden_check.ps1 -App unfold
.\scripts\build_apk.ps1 -App unfold
```
