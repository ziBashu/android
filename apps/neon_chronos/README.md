## Navigation

| Tab | Content |
|-----|---------|
| HOME | Customizable cockpit modules (long-press reorder, gear to toggle) |
| TIME | Digital HUD / Orbital / Quantum / Custom (tap to cycle) |
| WORLD | World network cities |
| ALARM | Wake events + phased Wake Sequence |
| TOOLS | Timer + stopwatch |
| MORE | Focus, Clock Builder, Theme Archive, Journey, Ambient, System |

## Highlights

- **Clock Builder** — shape, glow, particles, share `NC3:…` codes
- **Theme Archive** — Cyber City, Deep Space, Retro Terminal, Minimal White, Industrial
- **Focus** — Pomodoro + history + manual Time Map
- **Ambient** — desk mode; snackbar when charging
- **Wake Sequence** — glow → sound → vibration phases
